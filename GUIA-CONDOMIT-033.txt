PARA ATUALIZAR NO CELULAR VIA USB
1. Na raiz do projeto, execute: npm.cmd install (somente se node_modules ainda não existir).
2. Execute: npm.cmd run mobile:sync
3. Execute: npx.cmd cap open android
4. Conecte e autorize o celular por USB.
5. No Android Studio, selecione o aparelho e clique em Run 'app'.

Se o Gradle voltar a reclamar de C:\Users\...\.gradle\init.gradle ou init.d\repositories.gradle,
esses scripts globais precisam continuar desativados conforme a correção anterior.
