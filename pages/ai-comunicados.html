Sugestões de uso

Saiba como aproveitar melhor a IA para seus comunicados.

  • Inclua datas e horários para maior clareza
  • Especifique o bloco/apartamento se for algo pontual
  • Use o botão "Refinar" para ajustar o tom do texto
  • Sempre revise antes de enviar para os moradores
  • Categorize: Manutenção, Eventos, Avisos, Regras, etc.
  • Para comunicados urgentes, mencione "urgente" na descrição
