## 🐛 Troubleshooting

### Página não carrega?
```
1. Verifique se digitou a URL corretamente
2. Verifique se o arquivo existe na pasta /pages/
3. Feche e reabra o navegador
4. Limpe o cache do navegador (Ctrl+Shift+Delete)
```

### CSS não está sendo aplicado?
```
1. Verifique a pasta /styles/ contém os arquivos
2. Verifique se os caminhos estão corretos (../styles/)
3. Abra o console (F12) e procure por erros
```

### JavaScript não funciona?
```
1. Abra o console do navegador (F12)
2. Procure por erros de caminho (scripts/)
3. Verifique se os arquivos existem em /scripts/
4. Recarregue a página (F5)
```

### Sessão perdida?
```
- É normal! Feche a aba e toda sessão é perdida
- Faça login novamente para uma nova sessão
```
